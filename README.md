
# Uber Ride Analytics Dashboard | Power BI

## Project Overview
This project features an interactive Power BI dashboard that analyzes Uber ride data to uncover insights into Revenue, Booking Status, Payment Methods, Vehicle Types, and Customer Activity.

## Dashboard Highlights
- **Key Performance Indicators (KPIs):** Completed Rides, Revenue, Lost Bookings, and Distance.
- **Payment Analysis:** Revenue Breakdown by Payment Method.
- **Revenue Trends:** Monthly and Quarterly Revenue Analysis.
- **Vehicle Analysis:** Revenue Comparison Across Vehicle Types.
- **Customer Analysis:** Top Customers by Revenue.
- **Ride Status Analysis:** Completed, Cancelled, and Incomplete Rides.

## Tools and Technologies
- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Project Objective
To transform Raw Data into Meaningful Insights through Interactive Visualizations and support Data-Driven Decision-Making.
